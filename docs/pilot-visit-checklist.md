# Pilot visit checklist

One printable page. About 14 minutes with an owner who has their menu on hand. Print the same card from the app: add ?pilot to the end of the address (smokebox.html?pilot), then tap Print this card. Owners do not see it in Settings.

Nothing here has been tried on a real tablet or in a real kitchen yet. The times are a plan, not a measurement. Time the first visit and fix this page.

Bring: the tablet and its charger, a Wi-Fi password is not needed, a pen, the owner's menu (a spreadsheet or a photo of the menu board).

| # | Step | Minutes | Where | Done |
|---|------|---------|-------|------|
| 1 | Device checks: screen never sleeps, plugged in, sound test heard, added to the home screen, full screen | 3 | Settings, Device checks | |
| 2 | Put the menu in: import their spreadsheet, or add the first dishes by hand. Check the preview before saving | 3 | Settings, Dishes and prices | |
| 3 | Tax, hours and PIN: set the manager PIN and write down the recovery code with the owner | 2 | Settings, Tax, hours and PIN | |
| 4 | Name stations and menu sections in their words; hide stations they do not have | 2 | Dishes and prices, Change stations | |
| 5 | Cook-ahead question: Yes, No or Not sure (can be changed later) | 1 | Settings, How you serve | |
| 6 | One test ticket: New ticket, two dishes, send, bump. Watch that the right station sees it | 2 | Board | |
| 7 | Backup and who to call: show where to save a backup; leave a phone number | 1 | Back office, Menu and settings, Data | |
|   | **Total** | **14** | | |

## If something goes wrong
- No beep in step 1: raise the tablet volume, check the side or mute switch, try a small Bluetooth speaker. Do not skip it; a silent board is the biggest risk.
- Screen goes dark: set Auto-Lock to Never (iPad) or the longest Screen timeout (Android) and keep it plugged in.
- Import looks wrong: leave the rows unticked, add the first three dishes by hand, finish the visit, fix the file later.
- Forgot to write down the recovery code: Settings, Tax, hours and PIN, make a new one.

## After the visit
Write down how long each step really took and what the owner asked. Send both back so the times above can be corrected.
