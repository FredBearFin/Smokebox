# Replacing a device

Move Smokebox to a new tablet or computer and keep your menu, settings and history. The Data page has a card, **Replacing this device**, with the same steps.

1. On the old device, if it still works, download a backup (see Backup and restore). Copy the file somewhere else: email it to yourself or use a USB drive.
2. On the new device, copy the same smokebox.html file onto it and open it. Install it as an app: on an iPad tap Share, then Add to Home Screen. In Chrome tap the menu, then Install app.
3. Tap **Settings**, then **Device checks: screen, sound, home screen**. Sound and keeping the screen on are set on each device, so do them again here.
4. Tap **Back office**, then **Menu, prices and shop**. In the **Restore from a backup** card, choose the backup file, check the summary and tap **Replace everything with this backup**.
5. Check the board and your menu. Save a fresh backup from the new device, then retire the old one.

If the old device is broken and you have no backup file, its data cannot be recovered. This is why a daily backup matters.

Separate devices do not share data yet. Two tabs on the same device stay in step.
