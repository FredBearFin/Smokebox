# Start over with an empty menu

Empty your kitchen and begin again with a blank menu. When there are orders or tickets, a backup file is saved first.

## Only dishes so far

No tickets, orders or sales yet? Then nothing real can be lost. The screen says so and has one button: tap **Start over now**. No backup and no typed word are needed. **Save a copy of the old menu** on the last screen is there if you want it.

## With orders or tickets

1. Tap **Settings**. At the bottom, tap **Start over with an empty menu**. If a PIN is set, the PIN pad opens first.
2. Read what goes and what stays. Clear **Keep my tax, hours, PIN and station names** to reset those too. Tap **Next: about your backup**.
3. Tap **Save my backup file now**. The file downloads before anything is erased. Look in your downloads folder, select **I saved the backup file and I can find it**, then tap **Next: confirm**.
4. Type ERASE, then tap **Erase everything and start over**.
5. At "Done. Your kitchen is empty." tap **Save the backup again** or **Go to the first screen**.

This cannot be undone. Save a backup first: to go back, restore the backup file. Left-over old demo tickets get **Clear them** or **Keep them**.

With a PIN set, the PIN pad opens first. If the backup cannot be saved, nothing is erased.
