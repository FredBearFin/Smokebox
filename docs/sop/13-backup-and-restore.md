# Backup and restore

Everything Smokebox knows is saved in this browser on this device. A backup is a file you keep somewhere else.

## Make a backup

1. Tap **Back office**, then **Menu, prices and shop**.
2. Find Data, backup and reset. In the first card, **Back up now**, tap **Download backup (JSON)**. Or tap **Copy backup** and paste the text into an email to yourself.
3. Keep a copy off this device.

Back up every day at close. A copy kept only on this device is lost with it.

## Restore from a backup

1. In the second card, **Restore from a backup**, tap **Choose a backup file**. Pick the newest one, named smokebox-backup-(date).json. Or paste the text and tap **Check pasted backup**.
2. Read the summary: the date, tickets and batches should match what you expect. Nothing has changed yet.
3. If it is right, tap **Replace everything with this backup**. This replaces all data on this device, including the PIN and your station names. Back up what is here first if you might want it.
4. Open the board and check your menu and your food. Sound and loudness are set per device, so test them again.

After a restore the Data page says "Your kitchen before this restore is kept for" some days, with **Undo this restore**. Tap it, then **Put my old kitchen back** (or **Keep what I have**), and enter the PIN if one is set. If the browser was short on room, the copy keeps only recent tickets, or the restore says none could be kept.

The look, text size, sound and starting cash stay on each device and are not in a backup.

A file that is not a valid backup, a backup from the demo, or a spreadsheet file is refused, and nothing changes.

## Start over

To empty your kitchen and begin again with a blank menu, see Start over with an empty menu.

## Erasing

The Danger zone has **Erase tickets and records** and **Erase everything**. Each asks you to type a word first. Back up before using either. With a PIN set, these and **Replace everything with this backup** ask for the PIN first.

## How full the saved history is

Settings and the Data page show **Saved history**, how full this tablet is. When it is nearly full, **Close the month...** is offered there.
